# zmk-for-forager

ZMK config for a 34-key Forager (Seeed XIAO BLE).

## Branches

- **`main`** — original QWERTY keymap with ZMK Studio.
- **`Remap-v1`** — port of [urob's zmk-config](https://github.com/urob/zmk-config) system
  (homerow mods, magic-shift, smart-num, leader key, dense combos, NAV/FN/NUM/SYS/MOUSE
  layers) onto the Forager, keeping **QWERTY** alphas.

## Keymap diagram

Automatic keymap-drawer rendering is disabled on `Remap-v1`: this keymap is built on
urob's `zmk-helpers` macros, which keymap-drawer's preprocessor-only parser cannot
expand. A proper diagram pipeline is a pending follow-up.
